# 🤖 JOJO - AI Virtual Assistant

JOJO is a simple voice-controlled AI virtual assistant built using **HTML, CSS, and JavaScript**.

JOJO can listen to voice commands, respond using speech, tell the current time, open websites, and search Google for commands it doesn't recognize.

---

## ✨ Features

- 🎤 Voice Recognition
- 🔊 Voice Response
- 👋 Greeting System
- 🕐 Current Time
- 🌐 Open Google
- ▶️ Open YouTube
- 📘 Open Facebook
- 📸 Open Instagram
- 💼 Open LinkedIn
- 💻 Open GitHub
- 💬 Basic Conversation
- 🧮 Open Calculator
- 💬 Ask "How are you?"
- 🤖 Ask "Who are you?"
- 🔎 Search unknown commands on Google

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Web Speech API
- Speech Recognition API
- Speech Synthesis API
